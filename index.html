01 — Features

Four functions.
One pipeline.

01
compress_one_level()

Shrinks the image by half, recursively. Averages every 2×2 block into a single pixel — works natively with grayscale and RGB/RGBA.

02
decompress_nearest()

Fast upscaling that copies each pixel into a 2×2 block, producing a blocky, pixelated retro look.

03
decompress_bilinear()

Interpolates between neighboring pixels for a smoother, blended upscale — closer to a standard resize.

04
psnr()

Measures reconstruction quality with Peak Signal-to-Noise Ratio, so quality loss can be compared numerically.
